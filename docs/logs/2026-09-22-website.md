# Timosaic 官网与商店关键词

目标：官网继承 App 的文楷、纸色、植物与糖果时间格风格；GitHub + Vercel 发布，域名 timosaic.ahaknow.com。

范围：website 静态站点、部署配置、商店元数据及交接。未修改原生 App 行为。依据：项目 README、实际原生截图、content.cjs / render.cjs / build-gallery.cjs、字体许可、提醒与照片选择实现。

发现素材脚本误把中文关键词计为 UTF-8 字节；根据 Apple https://developer.apple.com/app-store/product-page/ 的 100 characters 要求，修复为 Unicode 字符计数。中英文各 99 字符；没有搜索量数据，不声称排名保证。关键词只描述已实现的记录、日历、复盘、心情、统计及本地隐私功能。同步元数据 JSON/TXT、素材 HTML、校验结果及 ZIP。

官网五页：中文/英文首页、双语支持、双语隐私、404。复用真实示例截图；涂色体验在页面内存中运行。Vercel 是部署状态事实源，网站本身没有异步业务状态。失败显示由 Vercel/HTTP 处理，没有虚构进度。

验证：python3 scripts/website/verify.py PASS（66 项本地链接与元数据检查，5 页，字体 <200KB）；node --check PASS。浏览器检查 390×844 中文与英文、默认桌面尺寸；手机无横向溢出（documentWidth=390），无损坏图片。点击 00:00 从空白变已涂，撤销恢复为空白。字体由本机 HarfBuzz 与 WOFF2 工具生成约 111KB 字形子集，原字体与许可保留来源。

商店 24 张截图及中英文元数据重新渲染校验通过；素材 ZIP 已重新生成。App Store Connect 本次尚未同步新的关键词，不能把本地更新当作后台已更新。

安全：.env.local 与 .vercel 被忽略；.vercelignore 只发布 website 与 vercel.json。源仓库此前没有提交；此次提交只纳入官网、商店素材及对应脚本，原生 App 与既有设计/测试文档仍留在本地，未擅自打包公开。
