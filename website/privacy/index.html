隐私政策
生效日期： 2026-09-22 · 适用于 Timosaic 1.0 与本网站

App 中的记录

时格由 AHAKNOW LLC 提供，无需注册账号。时间记录、日记、心情、标签、手动填写的地点、个人资料和设置保存在设备本地。当前版本没有云同步、广告 SDK 或分析 SDK，不会向我们上传这些记录，也不会自动监测活动或屏幕使用时间。

照片、提醒与地点

头像通过系统照片选择器选取，只使用你主动选择的照片。仅在开启提醒时申请通知权限，用于本地提醒。记录中的地点由你手动填写，App 不请求定位权限。你可在系统设置里更改通知权限。

导出、保留与删除

导出由你发起。导出的 JSON 或 CSV 文件可能包含个人内容，请妥善保存；你选择的分享或存储服务适用其自身隐私政策。可在 App 中删除记录；卸载会移除 App 本地数据。独立导出文件和由你管理的系统备份需分别处理。本版本不提供导入恢复。

网站与支持

官网由 Vercel 托管。访问时，托管服务可能处理 IP 地址、浏览器信息和请求日志以提供服务和保障安全。本网站不添加广告、分析脚本或跟踪 Cookie；涂色体验只保留在当前页面内存，刷新即清空。外部 App Store、GitHub 和 AhaKnow 链接适用相应网站的政策。通过 GitHub 提问时，请勿公开个人记录；你主动提交的信息用于处理该问题。

联系与更新

如有隐私疑问，可通过项目支持入口联系。请仅描述问题，不要在公开渠道附带敏感信息。政策变化将在本页注明新的生效日期。
