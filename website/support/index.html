时格使用帮助

记录、修改与保存

在「今天」选好活动，连续涂过时间格。每笔松手后自动保存；涂错可撤销或擦除，长按格子精确编辑。中间的 + 是快速记录草稿，点击完成才保存。

给今天写一篇日记

打开今天的「日记」，记录感受、心情、收获和明日期待。时段备注与全天日记分别管理；回顾可按日期查找。

导出与设备更换

在「我 → 数据导出」导出完整 JSON 或时间记录 CSV。1.0 不提供云同步和导入恢复；卸载 App 会移除本地数据。请先保存导出文件，再卸载或更换设备。

发现里的数字意味着什么？

统计只来自主动记录。睡眠参考与工作提醒可以调整，不是医疗建议。留白不当作休息；记录不足时不会给出无依据的比较。
